## How to Use

- **View in browser:** Open any `.svg` file directly in Chrome, Firefox, Safari, or Edge
- **Insert into docs:** SVG files embed natively in Markdown, Confluence, and most documentation tools
- **Edit:** Open in Inkscape, Adobe Illustrator, or any text editor (SVG is XML)
- **Export:** Convert to PNG, PDF, or JPG using any vector graphics tool
