# SAM Getting Started — Video Companion Slides

Slide-by-slide breakdown for the getting started video.

## Slide 1: Title (0:00)
**ServiceNow SAM — Getting Started**  
A beginner's guide to Service Asset Management  
Presented by opencode agent • 2026-11-04

## Slide 2: What is SAM? (0:30)
**SAM = Service Asset Management**  
Like a giant inventory for everything IT-related:
- Laptops, servers, phones
- Software licenses
- Maintenance contracts
- Where things are, who has them, when they expire

## Slide 3: What You'll Learn (1:00)
1. Log in and navigate to SAM
2. Understand foundation data
3. Create your first asset
4. Move an asset through lifecycle states
5. Create software licenses and contracts
6. Run a report

## Slide 4: Foundation Data (2:00)
**You can't create assets without foundation data first:**
- Companies / Vendors
- Locations
- Departments
- Asset Categories
- Asset States
- Users

## Slide 5: Create an Asset (4:00)
**Step-by-step:**
1. Asset Management > Assets > All > New
2. Fill in name, category, asset tag, serial number
3. Set state, purchase date, cost, vendor
4. Submit → note the asset number

## Slide 6: Lifecycle States (8:00)
**Asset journey:**
Requested → Ordered → Received → Assigned → In Repair → Retired

## Slide 7: Software License (12:00)
**Track software, not just hardware:**
- License count vs installation count
- Compliance = installations ≤ licenses
- Expiration dates

## Slide 8: Contract Management (15:00)
**Track vendor agreements:**
- Start date, end date, renewal date
- Contract value
- Link to vendor

## Slide 9: Common Mistakes (22:00)
1. Creating assets before foundation data
2. Not using asset tags
3. Forgetting to retire old assets
