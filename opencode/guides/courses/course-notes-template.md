## PDI Practice Checklist

Before moving to the next course, make sure you can:

- [ ] Create a new user and assign roles
- [ ] Create a new group and add members
- [ ] Create a custom table with fields
- [ ] Create a UI policy that makes a field mandatory
- [ ] Create a business rule that runs on insert
- [ ] Create a Flow Designer flow that triggers on record creation
- [ ] Create an asset category and state
- [ ] Create an asset record end-to-end
- [ ] Create a software license record
- [ ] Create a contract record
