## Example: Completed Template

```
CONCEPT: ServiceNow Software License Management

1. WHAT IS IT?
   ServiceNow Software License Management is the process of tracking software licenses, managing entitlements, and ensuring compliance with software vendor agreements.

2. WHAT PROBLEM DOES IT SOLVE?
   It ensures that organizations don't over-purchase licenses (wasting money) or under-purchase licenses (compliance risk and audit penalties).

3. HOW DO I USE IT?
   Step 1: Navigate to SAM → Software Licenses → All to see existing licenses
   Step 2: Click New to create a new license with name, license type, and entitlement count
   Step 3: Allocate license entitlements to devices/users and check compliance status

4. WHERE DOES IT LIVE?
   SAM → Software Licenses → All (in the Application Navigator)

5. WHAT TABLE DOES IT USE?
   alm_license

6. WHAT ROLE DO I NEED?
   sam_license_manager or sam_admin

7. WHAT BROKE AND HOW DID I FIX IT?
   I couldn't allocate a license because I didn't have the sam_license_manager role. I added the role to my user, logged out and back in, and it worked.

8. WHAT'S THE NEXT THING TO LEARN?
   ServiceNow Hardware Asset Management - how hardware assets are tracked and managed
```
