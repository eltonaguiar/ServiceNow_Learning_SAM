# Rapid Learning Checklist

**Agent:** Kilo  
**Date:** 2026-11-04

## Purpose

A quick-reference checklist for learning any ServiceNow SAM module or concept quickly. Print this or keep it open while you learn.

---

## Pre-Learning Checklist

- [ ] I have access to a ServiceNow instance (developer, test, or sandbox)
- [ ] I know my username and password
- [ ] I know my current roles
- [ ] I have a notebook or document for notes
- [ ] I have the SAM module name I want to learn
- [ ] I have allocated 60-120 minutes

---

## Step 1: Orient

- [ ] I found the SAM module in the Application Navigator
- [ ] I know the navigation path to the module
- [ ] I know the primary table name
- [ ] I know the required user role
- [ ] I can write a one-sentence description of what the module does

---

## Step 2: Configure

- [ ] I have the required role on my user account
- [ ] I logged out and back in after adding the role
- [ ] I can access the module without errors
- [ ] I created at least one test record
- [ ] I noted the sys_id of the test record

---

## Step 3: Build

- [ ] I chose a lab or task to complete
- [ ] I read the lab instructions before starting
- [ ] I completed all steps in the lab
- [ ] I created a working artifact (asset record, PO, contract, etc.)
- [ ] I can access my artifact from the UI

---

## Step 4: Verify

- [ ] I can see my record in the list view
- [ ] I checked related lists on the form
- [ ] I tested with a different user (if applicable)
- [ ] I checked the System Log for errors
- [ ] I can explain what the artifact does

---

## Step 5: Teach Back

- [ ] I can explain what the SAM module does in one sentence
- [ ] I can explain how to use it in 3 steps or less
- [ ] I know what breaks if I use it wrong
- [ ] I know what to learn next
- [ ] I wrote a summary using the concept template

---

## Daily Learning Checklist

- [ ] I learned something new today
- [ ] I built something that works
- [ ] I broke something and fixed it
- [ ] I documented what I learned
- [ ] I know what to learn tomorrow

---

## Common Red Flags (Stop and Re-read)

- [ ] I don't know which table stores the data
- [ ] I don't know which role I need
- [ ] I'm getting errors I don't understand
- [ ] I can't find the module in the navigator
- [ ] I'm copying code without understanding it
- [ ] I'm working on production

If any of these are true, STOP. Re-read `docs/methodology/rapid-learning-methodology.md` or ask for help.
