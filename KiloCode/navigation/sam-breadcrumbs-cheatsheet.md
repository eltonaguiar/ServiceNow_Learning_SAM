## Common SAM Tables

| Table Name | What It Stores | Common Fields |
|------------|---------------|---------------|
| `alm_asset` | All asset records | `number`, `name`, `asset_category`, `state`, `assigned_to` |
| `alm_hardware` | Hardware-specific assets | `serial_number`, `asset_tag`, `model`, `manufacturer`, `location` |
| `alm_software` | Software records | `name`, `version`, `manufacturer`, `publisher`, `category` |
| `alm_license` | Software licenses | `name`, `license_type`, `entitlement_count`, `allocated_count`, `compliance_status` |
| `alm_license_model` | License models | `name`, `license_metric`, `cost_per_license`, `currency` |
| `pm_purchase_order` | Purchase orders | `number`, `state`, `vendor`, `total_cost`, `currency`, `order_date` |
| `pm_line_item` | PO line items | `item`, `quantity`, `unit_cost`, `total_cost`, `category` |
| `pm_contract` | Contracts | `number`, `state`, `vendor`, `start_date`, `end_date`, `contract_value` |
| `cmdb_ci` | Configuration Items (servers, devices) | `name`, `ip_address`, `os`, `manufacturer`, `model` |
